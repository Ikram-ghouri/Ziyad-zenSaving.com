# Theme analysis
The theme registers coupon with coupon_store, coupon_category and coupon_tag taxonomies. Default routes are /coupon/, /store/, /coupon-category/ and /coupon-tag/; taxonomy rewrites are configurable through WordPress options and cannot be verified without the database. Single coupon visibility is also configurable. Coupons use _wpc_ metadata for code, sale, printable offer, destination, dates, shipping, usage and votes. Stores are terms with logo and affiliate URL metadata. Templates include store/category A–Z indexes and coupon submissions.

Scope: frontend only, as requested. No theme modifications or WordPress plugin are included. Live CMS options, page content, legal disclosure and post permalink structure require the live backend. Demo data must never be mistaken for verified offers. Staging remains noindex until explicitly enabled.
