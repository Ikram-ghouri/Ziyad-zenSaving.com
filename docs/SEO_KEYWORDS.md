# Zen Saving SEO keyword map

SEO is organized by search intent. The words below belong naturally in titles, descriptions, headings, introductions, internal links and useful page content. Avoid repeating them unnaturally.

| Page template | Primary keyword | Supporting keywords |
| --- | --- | --- |
| Homepage | coupon codes | promo codes, online deals, discount codes, verified coupons, free shipping deals |
| Store directory | coupon stores | stores with promo codes, brand coupon codes, all coupon stores |
| Store page | `[Store] coupon codes` | `[Store] promo codes`, `[Store] coupons`, `[Store] discount code`, `[Store] deals`, `[Store] free shipping` |
| Deals page | best online deals | top coupon codes, today's deals, verified promo codes, free shipping coupons |
| Category page | `[Category] coupons` | `[Category] promo codes`, `[Category] deals`, `[Category] discounts` |
| Special discount hub | special discounts | student discounts, teacher discounts, military discounts, senior discounts, healthcare discounts |
| Audience page | `[Audience] discounts` | `[Audience] coupon codes`, stores with `[Audience] discounts`, verified `[Audience] offers` |
| Blog | money saving tips | shopping guides, product reviews, coupon tips, how to save money online |

Do not target the same primary phrase on multiple pages. Each store, category and audience page needs original introductory copy, FAQs and update details from WordPress. Query and filtered pages should remain `noindex`.
